# 个人空间

中文响应式个人网站，使用原生 HTML、CSS 和 JavaScript，无构建依赖。

## 本地运行

在仓库目录执行：

```sh
python3 -m http.server 8000
```

在浏览器打开本地服务即可查看。部署时将 `index.html`、`style.css` 和 `script.js` 上传到任意静态网站托管服务。

## 替换个人资料

- `index.html`：修改个人介绍、标志、作品、页面标题和描述。
- 联系方式未配置，点击“联系我”会提示尚未公开。准备好公开邮箱后，可将该按钮改为 `mailto:` 链接并移除对应点击处理。
- `style.css`：在 `:root` 中调整主题颜色。字体加载失败时会自动使用系统字体。

作品中的“日常观察计划”为示例构想，请按实际情况修改。
